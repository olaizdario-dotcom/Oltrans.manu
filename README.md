## 📋 Descripción del Proyecto
Este proyecto es un sitio web de 5 secciones diseñado con una metodología Mobile-First. Cuenta con maquetación estructurada, diseño responsivo y personalización visual.

### Páginas incluidas:

- **Inicio (`index.html`)**: Presentación principal y destacados.
- **Sobre Nosotros (`sobre-nosotros.html`)**: Información sobre el equipo y visión.
- **Proyectos (`proyectos.html`)**: Galería de trabajos realizados.
- **Contacto (`contacto.html`)**: Formulario y canales de comunicación.
- **Servicios (`servicios.html`)**: Detalle de propuestas ofrecidas.
